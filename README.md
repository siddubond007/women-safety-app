# Women Safety App

A Flutter-based women-centric safety, community and wellness application.

## Repository layout

- `app/` — Flutter client targeting Android, iOS and web, with shared Dart code.
- `backend/` — shared server-side API and business logic.

The backend framework, database and external services will be selected after reviewing the approved requirements.

## Flutter development

Run these commands from the `app/` directory:

```powershell
flutter pub get
flutter run
```

The backend is not implemented yet. Do not treat placeholder documentation as working backend functionality.
